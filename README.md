# DevConnect

A full-stack MERN social networking application built using React, Node.js, Express.js, and MongoDB.

## Features

- User Authentication
- Developer Feed
- Send & Accept Connection Requests
- View Connections
- Profile Management
- Responsive UI

## Tech Stack

- React
- Redux Toolkit
- Node.js
- Express.js
- MongoDB
- Mongoose
- Tailwind CSS
- DaisyUI
- JWT Authentication

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
